silentscan/deprecated-syntax/task-comment-todo

Why is this an issue?

A comment contains an untracked "TODO" marker.

A comment contains an untracked "TODO" marker. Left in the source with no ticket or owner attached, it tends to sit unresolved indefinitely - the comment records that something was left unfinished, but nothing tracks whether it ever gets done.

How can I fix it?

Either resolve the TODO now, or replace it with a reference to a tracked work item so it has an owner and a way to be closed out.

An untracked TODO marker

Noncompliant code example

-- TODO: handle the cancelled-order case
SELECT OrderId FROM dbo.Orders WHERE Status = 'Active';

The TODO names a gap in the logic but is not linked to any tracked work item, so it is easy to lose track of.

Compliant solution

-- See work item ORD-482: handle the cancelled-order case
SELECT OrderId FROM dbo.Orders WHERE Status = 'Active';

The comment now references a tracked work item, giving the gap an owner and a way to be closed.
