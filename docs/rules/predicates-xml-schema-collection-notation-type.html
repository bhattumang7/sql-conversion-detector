Xml Schema Collection Notation Type

silentscan/predicates/xml-schema-collection-notation-type

A medium-confidence or low-confidence finding of this same rule links here too - only the finding's certainty differs, not the underlying issue.

Why is this an issue?

A CREATE/ALTER XML SCHEMA COLLECTION's inline XSD text uses the built-in XML Schema type NOTATION - as an element's or attribute's declared type, or as an xs:extension/xs:restriction base - oracle-confirmed (Msg 9337: "The XML Schema type 'NOTATION' is not supported.") the schema collection never registers, regardless of where in the schema NOTATION is referenced. Statically decidable from the embedded XSD text (namespace-aware: any prefix bound to the XML Schema namespace is recognized, not just the literal 'xs:' prefix).

SQL Server's XML schema collection support does not implement the built-in XML Schema type `NOTATION` anywhere in a schema - as an element's type, an attribute's type, or an `xs:extension`/`xs:restriction` base. Confirmed directly against a real SQL Server instance: `CREATE XML SCHEMA COLLECTION` (or `ALTER ... ADD`) fails with Msg 9337 ("The XML Schema type 'NOTATION' is not supported.") the moment the inline XSD text references it anywhere, regardless of whether the schema is otherwise valid XSD.

The check is namespace-aware, not text-matching on a literal `xs:` prefix - a schema that binds the XML Schema namespace to a different prefix (or uses it as the default namespace) is still recognized.

How can I fix it?

Remove the NOTATION type from the schema - model the value as a string, or as an enumeration of `xs:string` values, instead.

An attribute typed xs:NOTATION never registers

Noncompliant code example

CREATE XML SCHEMA COLLECTION dbo.OrderSchema AS N'
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:complexType name="Order">
    <xs:attribute name="Format" type="xs:NOTATION"/>
  </xs:complexType>
</xs:schema>';
-- Fails: Msg 9337, the XML Schema type NOTATION is not supported.

Format is declared xs:NOTATION - this schema collection never registers, every time this statement runs.

Compliant solution

CREATE XML SCHEMA COLLECTION dbo.OrderSchema AS N'
<xs:schema xmlns:xs="http://www.w3.org/2001/XMLSchema">
  <xs:complexType name="Order">
    <xs:attribute name="Format" type="xs:string"/>
  </xs:complexType>
</xs:schema>';

Format is declared xs:string - the schema collection registers.
